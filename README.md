# AVX-512 `VINSERTF64X4` Instruction Parser & Encoder

Учебный легковесный ассемблер/кодировщик для инструкции **AVX-512 `VINSERTF64X4`** на чистом языке C. 

Программа принимает на вход ассемблерную строку, валидирует синтаксис, нормализует её в канонический вид и генерирует соответствующий машинный код (hex-байты) в формате архитектуры **x86-64** с 4-байтовым префиксом **EVEX**.

---

## Особенности

- **Zero-Dependency (Без зависимостей):** Все строковые и вспомогательные функции (`strlen`, `strcmp`, `memset` и др.) реализованы с нуля. Используется только `<stdio.h>` для ввода-вывода.
- **Поддержка EVEX-префикса:**
  - Расширенный регистровый файл: `ZMM0`–`ZMM31`, `YMM0`–`YMM31`.
  - Маскирование предикатами: `{k1}`–`{k7}`.
  - Режим обнуления (Zeroing): `{z}`.
  - Корректное формирование битов расширения: $R, R', X, B, v, V'$.
- **Гибкий парсинг адресации памяти (ModR/M + SIB):**
  - Поддержка произвольного порядка: `[base + index*scale + disp]`.
  - Масштабирование индекса (Scale): `1`, `2`, `4`, `8`.
  - Обработка ограничений x86: запрет `RSP` в качестве индексного регистра, автозамена местами `base` и `index`.
  - Адресация только по смещению (Direct/Absolute displacement).
- **Сжатое смещение (Compressed Displacement / Disp8\*N):**
  - Автоматическое сжатие смещений, кратных размеру операнда памяти (32 байта для 256-битного вектора), в 1-байтный `disp8` диапазона $[-4096; 4064]$.
- **Канонизация:** Вывод инструкции в стандартизированном виде перед кодированием.

---

## Формат инструкции

Инструкция `VINSERTF64X4` вставляет 256-битное значение (из регистра `YMM` или памяти `m256`) в указанную половину 512-битного регистра `ZMM`:
**Пример испольхования:
**VINSERTF64X4 zmm1 {k1}{z}, zmm2, ymm3/m256, imm8
**Enter AVX-512 command:
> vinsertf64x4 zmm5{k2}{z}, zmm10, ymm15, 0x01

1) Original command:    vinsertf64x4 zmm5{k2}{z}, zmm10, ymm15, 0x01
2) Canonical form:      VINSERTF64X4 zmm5{k2}{z}, zmm10, ymm15, 0x01
3) Machine code:        62 D3 AD A2 1A EF 01
